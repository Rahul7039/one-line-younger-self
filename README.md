## The line

> That joke you told at fourteen that nobody laughed at — tell it again at thirty, when the whole room roars, and keep telling it.

One sentence, 128 characters — the single line the writer would send back to their younger self if one line were all they got.

## Run it

```sh
python3 main.py
```

This writes the line verbatim to `/output/entry.txt` and prints it.
