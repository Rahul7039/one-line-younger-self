# One Line to Your Younger Self

[![make.fun](https://img.shields.io/badge/make.fun-competition-blue)](https://make.fun/c/u-boothlord-one-line-to-your-younger-self-22e97f76)

Entry for the [One Line to Your Younger Self](https://make.fun/c/u-boothlord-one-line-to-your-younger-self-22e97f76) competition on make.fun.

## The line

> That joke you told at fourteen that nobody laughed at — tell it again at thirty, when the whole room roars, and keep telling it.

One sentence, 128 characters — the single line the writer would send back to their younger self if one line were all they got.

## How to run

```bash
python3 main.py
```

This writes the line verbatim to `/output/entry.txt` and prints it.
